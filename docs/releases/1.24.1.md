## Fixed

- **Top edge on a Mac with a notch** — hovering the Mac's notch now grows the deck down out of it, a solid black panel with the rings and the deck's cells in a row beneath the notch. Folded, it is the Mac's own notch and nothing more, and only the notch itself wakes it. It used to squeeze the rings into a menu-bar-height strip beside the notch, which with the deck's cells ran across the menu bar. The old layout is still there: **Settings → Appearance → At the Mac's notch → Beside the notch**.
- Reaching the notch opens it without popping a card; a card opens when you move onto a ring.
- Settings reopens on the pane you last looked at.
- The clipboard card says how to use it while the history is short.

## Install

Already on 1.24.0? NotchDeck offers this update in the notch — choose **Update** — or press **Settings → General → Check for Updates**.

- **macOS 15 or later** — download `NotchDeck.dmg`, drag NotchDeck to Applications, then clear the download quarantine once (the build is ad-hoc signed, not notarized):

  ```sh
  xattr -dr com.apple.quarantine /Applications/NotchDeck.app
  ```

- **Windows 10/11** — download `NotchDeck-Setup.exe` and run it. It is not code-signed, so SmartScreen asks first: **More info → Run anyway**.
