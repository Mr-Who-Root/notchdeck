NotchDeck: Now Playing, clipboard history and a focus timer, right beside the usage rings.

## New

- **Now Playing** — what's playing in Music, Spotify, a podcast app or a browser, with artwork, a scrubber and previous / play-pause / next. Click the cell to play or pause.
- **Clipboard history** — the text, links, files and images you copied. Click a clip to copy it again, pin the ones you reuse, and hover a long one to read it in full. Nothing a password manager copies is ever recorded.
- **Focus timer** — pick a length and click the cell to start; the notch opens with a chime when time is up.
- **Settings → Deck** to switch each tool on or off, and a new **General** page with the app's version, **Check for Updates** and its release notes.
- Updates now come from this repository's releases, on macOS (Sparkle) and Windows.

## Install

- **macOS 15 or later** — download `NotchDeck.dmg`, drag NotchDeck to Applications, then clear the download quarantine once (the build is ad-hoc signed, not notarized):

  ```sh
  xattr -dr com.apple.quarantine /Applications/NotchDeck.app
  ```

- **Windows 10/11** — download `NotchDeck-Setup.exe` and run it. It is not code-signed, so SmartScreen asks first: **More info → Run anyway**.
